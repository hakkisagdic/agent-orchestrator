Against the row's promise:

1. **Unavailability comes from the transport** — met. `_run_reviewer` classifies spawn
   failure, exit status, silence and timeout. Prose decides only a legacy file with no
   verdict line and no evidence, which authorises nothing.
2. **A fallback never supersedes a completed rejection** — met, now including an answer
   a person carries from a stand-in session, which is recorded as a fallback
   (REVIEWER-HONESTY). Such an approval ends no round count either (ROUND-LEDGER).
3. **Eligibility in every mode** — met. Without a matrix a route is refused when it runs
   as the implementer's session, declares the implementer's family, or runs the
   implementer's engine without two differing declared families; `ao review`, its
   fallbacks, the reviewer probe and `ao commit-ok` apply the same rule. **Declined:** the
   family of a stand-in session is the person's declaration and cannot be measured
   ([standin.md](../standin.md)); it is recorded with its limits and as a fallback.
4. **Timeout from configuration** — met: `review_timeout`, never the command line.
   `.ao/config.json` remains writable by whoever can write the tree; a project that
   must not trust that uses the capability matrix, and the implementer's tool grant
   is checked by the doctor (#58).
5. **A round exactly when a verdict was produced** — met for every review ao recorded:
   the count reads verdict rows of the chained review ledger. Files from before the
   ledger are still read by file time, so a slice begun before it keeps its count.
